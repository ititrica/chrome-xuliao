ChatGPT 页面适配

默认适配 ChatGPT。网页更新后，可用 CSS 选择器修正定位。留空使用内置规则；未来接入你自己的聊天网页时，也需更新插件的网站权限和适配器。

聊天库与记录

内置 380 组会话，包含 280 组文字主题和 100 组连续图片创作主题，共 6,200 轮提示词。文字随机取 6–15 轮，图片随机取 12–20 轮，首轮直接生图，后续逐轮修改上一张图。每批随机抽取不同的话题，下一批可能再次抽到。

编辑聊天库不会改变已启动任务的提示词。导出的对话记录包含文字和图片链接，图片原文件需在聊天网页保存。开始新批次前，可先导出本批记录。
