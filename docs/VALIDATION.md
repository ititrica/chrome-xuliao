## 0.3.2（2026-11-11）

修复部分 ChatGPT 生图回复已经显示图片但插件仍等待的问题。原因是旧适配器只在助手正文区块内找图片，并对普通图片应用 `naturalWidth >= 128` 门槛；新版画廊可能把已加载缩略图放在助手文字的兄弟容器，或返回小于门槛的预览，导致 `images=[]`。现在优先读取当前回合的 `generated-image-gallery`，画廊内图片只要求加载完成且自然宽度大于 0，并把宽度为 0 或仍在加载的画廊图片标记为 pending；无标准助手标题时也能从画廊恢复助手候选。

提示词抖动新增语气范围：礼貌、普通、随意、不太礼貌。启动每组会话时随机抽取一个语气档案，整组所有轮次复用该档案；下一组重新抽取。配置迁移会为旧版已开启其他抖动范围的用户自动加入语气，显式空选择保持关闭。控制台增加“语气（组内固定）”选项，预览显示本组语气。
