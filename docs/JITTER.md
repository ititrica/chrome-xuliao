# 提示词抖动与独立分类词库

0.3.0 默认开启。词库共有 66 类，按分类计 3,246 条、去重后 3,236 个词语和自然短语。非数字词语独立去重后也超过 2,000 个；地点氛围分类包含兼容的地点组合短语，其余分类逐项维护。

## 使用

运行任务页有提示词抖动总开关，可单独选择主题侧重、场景与词语、数字。只希望改变措辞时，保留总开关但取消三个范围。需要逐字使用原文时关闭总开关。悬浮菜单有总开关，范围沿用控制台。

“抖动词库”可搜索、分类浏览和导出。聊天库每组的“预览抖动”显示替换对照和全部后续轮次，可反复本地抽样。正式任务启动时重新抽取，预览不会消耗 AI 配额或改变正在运行的任务。

## 抽样规则

1. 主题侧重按当前会话分类匹配，抽一个适合的关注方向。例如故事可侧重陌生人的善意，旅行可侧重公共交通衔接，图片可侧重材质触感。它作为偏好加入首轮，正文明确条件优先。
2. 场景与词语从首轮可编辑正文识别，按兼容的语义分类抽取，最多变更三项。一个分类中只选一个源词；优先完整词语，避免同一词被多个规则覆盖。服饰按围巾、帽子、衣装分开，城市分地区，角色、材质和画风分别抽取。
3. 数字识别首轮的数量和单位，在对应的词库数值中小幅选择。重复数值、中文与阿拉伯数字、常见单位别名使用同一映射。同量纲采用同一比例方向，保留数量之间的先后关系；计划时长不短于后续明确引用的最晚序号。一周内的天数不超过七天。
4. 替换以原文一次完成，抽出的词语不会再次被其他规则替换。整组采用同一映射，随后为每轮生成不同的礼貌开头和衔接语。最终提示词与映射在启动时持久化；暂停、恢复和重试不会再抽一次。

示例：

```text
原始：为两位第一次去京都的成年人安排三天慢旅行，住在京都站附近。
抽样：为三位第一次去鹿儿岛的成年人安排四天慢旅行，住在鹿儿岛站附近。

原始：海边小书店的灰猫，水彩绘本风。
抽样：晨光中的河畔咖啡馆的三花猫，钢笔淡彩风。
后续：保持三花猫的外观，继续调整上一张图。
```

这里只展示可能的组合。正式结果取决于随机抽中的分类、参数和正文中实际能匹配的词。

## 保留的内容

代码块、行内代码、网址、引号内的原文、可解析的完整 JSON 不做语义替换。序号、日期和范围保留；首轮生成“一张图片”保持不变。普通文本数字需带支持的量纲或数量单位才会参与。会话运行轮数另由文字 6–15 轮、图片 12–20 轮抽样决定。

词库依靠分类和精确匹配，不能推理任意自定义脚本的全部隐含关系。强约束自定义脚本可先预览，按需关闭场景或数字抖动。未知会话分类仍可调整措辞和匹配的数字，不强行套用其他主题的侧重。

## 记录与维护

task.jitter 保存词库版本、主题和替换列表；task.turns 保存实际文本及 sourceText。每轮导出包含 prompt、sourcePrompt、jittered，可对照实际发送结果。

用户可导出词库 JSON；开发源为 scripts/generate-lexicon.py，运行后同时更新 data/jitter-lexicon.json 和运行时 ESM 模块 data/jitter-lexicon.js。npm run check 核对二者一致并验证去重数量。修改词库和重新加载插件仅影响以后启动的批次。
